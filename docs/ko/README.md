# Security research

[English](../../README.md) | 한국어

이미 공개된 스마트 컨트랙트 공격을 하나 골라서, 논문이나 사후 분석 글을 보고 처음부터 다시 만든 다음, 로컬 테스트에서 실제로 터지는지 확인합니다. 항목 하나에 글 하나, Foundry 프로젝트 하나가 딸립니다. 프로젝트는 clone 받아서 그대로 돌릴 수 있습니다. 글에는 원 자료가 뭐라고 주장했는지, 제가 만든 버전이 실제로 뭘 했는지를 적습니다.

재현에 실패한 항목도 왜 안 됐는지까지 적어서 인덱스에 남깁니다.

## 항목 구성

글은 전부 [TEMPLATE.md](TEMPLATE.md)를 따릅니다. 원 자료의 주장, 제가 돌린 환경(fork block과 EVM 버전 포함), 취약 패턴, 숫자가 들어간 결과, 원 자료와 갈라진 지점, 검증하지 않은 것 순서로 적습니다.

항목마다 원 자료가 코드까지 같이 냈는지, 그 코드가 지금도 돌아가는지 함께 기록합니다.

## 범위

여기 올라오는 건 전부 이미 공개된 공격입니다. 대개 논문, 감사 리포트, 공개된 사후 분석입니다. 실행은 로컬 fork와 테스트넷 배포에서만 하고, 자금이 들어 있는 라이브 컨트랙트는 건드리지 않습니다.

제로데이를 찾자고 하는 작업은 아닙니다. 그래도 재현을 하다 보면 가끔 걸리는데, 대부분 원본 코드를 패치 없이 그대로 fork한 쪽입니다. 그런 경우 해당 팀에 먼저 알리고, 항목은 패치와 공개가 끝날 때까지 여기 올라오지 않습니다. 이미 올라온 항목이 아직 패치 안 된 라이브 코드를 가리키는 것 같으면 알려 주세요. 연락처는 [SECURITY.md](SECURITY.md)에 있습니다.

## 항목 실행

`reproductions/NNN-slug/` 하나하나가 독립된 Foundry 프로젝트입니다. 레포 루트에서 한꺼번에 빌드하는 건 없습니다.

```sh
cd reproductions/001-slug
forge install
forge test -vvv
```

Fork 테스트에는 archive node가 필요합니다. 여기서 다루는 공격은 대부분 몇 년 전 블록에서 일어났고, 무료 티어 엔드포인트는 그 블록 높이의 state를 안 내줍니다. 이때는 그냥 테스트 실패로 떠서 PoC가 깨진 건지 노드 문제인지 구분이 안 됩니다. `.env.example`을 `.env`로 복사하고 `ETH_RPC_URL`을 채우세요. 항목이 다른 체인을 쓰면 그 체인 값을 채우면 됩니다. `ETHERSCAN_API_KEY`가 같이 들어 있는 이유는, `cast etherscan-source`로 피해 컨트랙트 소스를 받아 오는 게 준비 작업의 대부분이기 때문입니다.

프로젝트마다 `foundry.toml`에서 `solc_version`과 `evm_version`을 직접 고정합니다. 기본값을 그냥 따라가지 않는 건 의도한 겁니다. 2021년 공격을 Cancun EVM에서 돌리면 같은 공격이 아닙니다. EIP-6780이 SELFDESTRUCT 동작을 바꿨고, 그 시절엔 PUSH0가 없었습니다. 특정 EVM 버전에서만 재현되는 항목이 있다면 그것도 글에 적습니다.

## 소개

한국에서 활동하는 독립 보안 리서처입니다. 직전에 만든 건 [Perp DEX](https://github.com/dandel6/dex)입니다. 하이브리드 무기한 선물 거래소인데, 매칭은 Rust 엔진이 오프체인에서 돌리고 정산 컨트랙트는 Arbitrum Sepolia에 올렸습니다. EIP-712 검증과 증거금 재검증은 OpenZeppelin 없이 만들었습니다. 담보 들고 있는 컨트랙트를 일 년 붙잡고 있다 보니 깨는 쪽이 궁금해졌습니다.
